# Spring MVC Project

## 📌 Description
Ce projet est une application web développée avec le framework **Spring MVC** en architecture **MVC (Model - View - Controller)**.

L’objectif du projet est de démontrer la mise en place d’une application Java Web en utilisant les concepts fondamentaux de Spring :

- Gestion des contrôleurs
- Injection de dépendances
- Gestion des vues
- Routing des requêtes HTTP
- Architecture MVC
- Intégration avec JSP / Thymeleaf
- Gestion des données

Ce projet est idéal pour apprendre le développement backend Java avec Spring MVC et comprendre le fonctionnement des applications web modernes.

# ⚙️ Installation et exécution

## 1️⃣ Cloner le projet

```bash
git clone https://github.com/MohamedSAIFI0/Spring-MVC.git
```

## 2️⃣ Accéder au dossier

```bash
cd Spring-MVC
```

## 3️⃣ Compiler le projet avec Maven

```bash
mvn clean install
```

## 4️⃣ Lancer le serveur

Déployer le projet sur :

- Apache Tomcat
- IntelliJ IDEA
- Eclipse STS

Puis accéder à :

```bash
http://localhost:8080/
```

# 🧠 Concepts Spring MVC utilisés

## 🔹 Model
Contient les données et la logique métier.

## 🔹 View
Interface utilisateur affichée au client (JSP / Thymeleaf).

## 🔹 Controller
Reçoit les requêtes HTTP et retourne les vues correspondantes.

## 🔹 DispatcherServlet
Composant central de Spring MVC qui gère le routage des requêtes.
